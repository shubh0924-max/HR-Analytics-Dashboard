# HR Analytics Dashboard

An HR Analytics project focused on understanding employee distribution, salary patterns, performance, workforce characteristics, and employee attrition using data analysis and interactive dashboards.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- PostgreSQL
- Power BI

## 📊 Project Highlights

- Analyzed employee demographics and workforce distribution.
- Studied employee attrition across departments, job roles, overtime, marital status, and performance rating.
- Performed SQL-based HR analysis using PostgreSQL.
- Built an interactive two-page Power BI dashboard.
- Created KPIs for total employees, employees left, attrition rate, average age, average tenure, and average monthly income.

## 🎯 Objective

The objective of this project is to analyze HR data and identify patterns related to employee demographics, compensation, performance, workload, and attrition.

## 🔍 Key Areas Analyzed

- Department-wise employee distribution
- Age-group distribution
- Job-role distribution
- Gender distribution
- Overtime and attrition
- Department-wise attrition
- Job-role-wise attrition
- Marital-status-wise attrition
- Performance rating and attrition
- Monthly income analysis
